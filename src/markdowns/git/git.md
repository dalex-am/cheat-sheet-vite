### Как git хранит историю изменений:

**Ключевые принципы хранения:** 

- **Снимки, а не разницы:** При коммите Git фиксирует, как выглядит каждый файл в данный момент.
- **Оптимизация:** Если файл не менялся с прошлого коммита, Git не копирует его заново, а создает ссылку на уже сохраненную ранее версию.
- **Объекты базы данных:** Данные хранятся в папке .git в виде трех основных типов объектов:
  - **Blob (Binary Large Object):** Содержимое файла.
  - **Tree:** Аналог директории, связывает имена файлов с их blob-объектами.
  - **Commit:** Снимок верхнего уровня (корневого дерева), родительский коммит и метаданные.
- **Хеширование:** Каждый объект идентифицируется уникальным \(SHA-1\) хешем (контрольной суммой).
- **Пакфайлы (packfiles):** Для экономии места Git упаковывает объекты, сохраняя только различия (delta compression) между похожими версиями файлов, если это эффективно. История формируется путем перебора ссылок на родительские коммиты, начиная от текущего указателя HEAD.

### Альтернатива git submodules

**git subtree**

Поддерево Git — это метод вложенности одного репозитория Git в подкаталог другого репозитория с сохранением возможности двусторонней отправки и получения изменений. Он интегрирует код и историю внешнего репозитория непосредственно в основной проект, в отличие от подмодулей Git, которые хранят только ссылку на конкретный коммит.

**Добавление поддерева:**

`git subtree add --prefix {local directory being pulled into} {remote repo URL} {remote branch} --squash`

(Пример: `git subtree add --prefix subtreeDirectory https://github.com/newfivefour/vimrc.git master --squash`)

**Пулл новых коммитов:**

`git subtree pull --prefix subtreeDirectory https://github.com/newfivefour/vimrc.git master --squash`

Если вы внесете изменения в subtreeDirectory, коммит будет сохранен в основном репозитории. Это самое большое отличие от подмодулей.

Если вы хотите обновить удаленный репозиторий поддерева с помощью этого коммита, выполните ту же команду, исключив `--squash` и заменив `pull` на `push`.

`git subtree push --prefix subtreeDirectory https://github.com/newfivefour/vimrc.git master`

### Методики обеспечения безопасности git:

- **Контроль доступа:** SSH-ключи, 2FA (двухфакторная аутентификация), минимизация прав пользователей - RBAC (Role-Based Access Control)
- **Защита репозитория:** Защита веток (запрет прямых пушей), требование PR/MR, проверки перед слиянием
- **Использование gitignore**
- **Использование git-secrets** для скрытия паролей, ключей и прочего. Сюда же - git-crypt для шифрования, последующая фильтрация "секретиков" через git filter-repo
- **Регулярные обновления**

### Фильтры git

На примере нормализации концов строк (CRLF ↔ LF) в .gitattributes:

```
# Автоматическое преобразование для Windows
*.txt text eol=crlf
*.sh text eol=lf
```
